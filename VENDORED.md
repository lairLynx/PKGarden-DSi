# Vendored: PKSM-Core (`arm9/core`)

- Upstream: https://github.com/Flagbrew/PKSM-Core
- Commit: `6cba517305261f88fff0d27ede46e568e0367555` (former pkmn-chest submodule pin)
- Copied without git metadata; this is a plain directory in this project.

## Local patches
1. `source/sav/Sav3.cpp` `Sav3::loadBlocks`: throws `std::runtime_error` when block 0, 1 or 5-13 is
   missing (previously left `blockOfs` at `INT_MIN`, causing wild reads). `main.cpp` catches `std::exception`.

Related non-core patch: `arm9/source/manager.cpp` `transferOrEmpty()` null-checks `Sav::transfer()`.
- Makefile: GIT_VER falls back to 'pkgarden-dev' when there is no git checkout (the fork has no .git).

## Shared with PKGarden-Knulli (not vendored: our own code)
`arm9/source/pkgarden/` is a copy of Knulli's `src/chest`, `src/gba/Convert.*` and `src/util` (chest file, journal,
envelope conversion, tiny filesystem shim). Knulli's `src/` is the single source of truth: edit it there, then run
`sync-chest-code.ps1` (and `sync-chest-code.ps1 -Check` to verify). Built with `-DPKG_NO_STD_FILESYSTEM` (no `<filesystem>`
on the DSi) and without RTTI.

## Removed from the vendored core (unused by this build)
`arm9/core`: the library's own `Makefile`, `.gitmodules`, `.gitignore`; `pcg-cpp`: `sample/`, `test-high/`, `Makefile`,
`.gitignore`, `CONTRIBUTING.md` (only `pcg-cpp/include` and the license files are needed).

## Splash screen (our own code, shared with other lairLynx Studios apps)
`arm9/source/splash/` is the startup splash from NDSi-Shop / StarDSi (same look, same code). `splash_logo.c` is generated by
`tools/pack_logo.ps1` from `assets/lairlynx_logo.jpg`.
